# Cyber Office — пилот v3

## Что работает без серверной части
- Экспресс-аудит → «Сделаю сам» → `/iphone/` (обзор шести настроек).
- Шесть независимых карточек по приоритету риска, отметки выполнения в localStorage.
- Краткие рекомендации и проверка доступны без контакта.
- Отдельная полная инструкция `/iphone/full.html` для ручной отправки пользователю после обращения.
- Заявка через Telegram: браузер открывает чат, текст нужно вставить и отправить самому.
- Кнопка помощи за донат открывает Telegram. **Оплата не интегрирована**.
- Экстренная памятка `/iphone/emergency.html` доступна без контакта.

## Ограничения перед публичным запуском
1. `policy.html` — черновик, нужно заполнить фактического оператора и согласовать документ; до этого форму нельзя запускать для реального сбора ПДн.
2. Для email-заявок нужен реальный адрес/приёмщик; сейчас интерфейс честно сообщает, что канал не подключён.
3. Полная инструкция — обычная публично доступная страница по ссылке, **не защищена авторизацией**; ссылку можно переслать.
4. Нет приёма платежей, CRM, автоматической проверки настроек и аналитики; есть протоколы и схемы в `docs/`.
5. Перед публикацией проверьте корректность всех iOS-путей на реальных версиях устройств и правила работы с ПДн.

## Локальный запуск
`python3 -m http.server 8000` из корня; открыть `http://localhost:8000/`.

## Ручной пилот
Когда пользователь пишет в Telegram, специалист фиксирует заявку в защищённом реестре (не в публичном GitHub), отправляет ссылку `https://<ваш-домен>/iphone/full.html` и отмечает факт отправки. Не просить пароли или SMS-коды.
